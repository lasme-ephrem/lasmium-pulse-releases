# Documentation

These documents are written in French, the language of the project's first users:

- [GUIDE_UTILISATEUR.md](GUIDE_UTILISATEUR.md) — complete user guide (multi-view, audio solo, chat, Twitch account, past broadcasts, installation, privacy).
- [ARCHITECTURE.md](ARCHITECTURE.md) — technical notes (HLS proxy and M3U8 filtering, chat, Twitch account, EventSub, library, VOD, distribution).

The English [README](../README.md) covers installation, configuration and security. An English translation of the guide will follow if users ask for it: contributions are welcome.

`icons/` holds the [Lucide](https://lucide.dev) icons (ISC licence, see `icons/LICENSE`) used by both READMEs, coloured with the app's signal accent `#FF3E1D`.
